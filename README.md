# ETL Miguel

Projeto ETL (Extract, Transform, Load) desenvolvido em Python.

## Descrição

Este projeto realiza operações de extração, transformação e carregamento de dados, incluindo integração com APIs externas.

## Requisitos

- Python 3.x
- requests

## Instalação

1. Clone o repositório:
```bash
git clone <url-do-repositorio>
cd etl-miguel
```

2. Instale as dependências:
```bash
pip install requests
```

## Uso

Execute o script principal:
```bash
python meuscript.py
```

## Estrutura do Projeto

```
etl-miguel/
├── meuscript.py     # Script principal
└── README.md        # Documentação do projeto
```

## Funcionalidades

- Requisições HTTP para APIs externas (GitHub API)
- Tratamento de erros com try/except
- Verificação de status HTTP das requisições
- Timeout configurável para requisições
